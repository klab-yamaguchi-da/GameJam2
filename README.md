# GameJam2

社内ゲームジャム向けWeb3ゲーム開発プロジェクト

## 概要

このリポジトリは、社内ゲームジャム向けにWeb3技術を使用したゲームを開発するためのプロジェクトです。GitHub Pagesを使用してゲームを公開します。

## 技術スタック

- **フロントエンド**: HTML5, CSS3, JavaScript
- **Web3**: ブロックチェーン連携機能（今後実装予定）
- **ホスティング**: GitHub Pages

## プロジェクト構造

```
GameJam2/
├── .github/
│   ├── copilot-instructions.md  # GitHub Copilot向けの開発指針
│   └── workflows/               # GitHub Actionsワークフロー
├── docs/                        # GitHub Pagesコンテンツ（ゲーム本体）
│   ├── index.html              # ゲームのエントリーポイント
│   └── favicon.ico             # ファビコン
└── README.md                    # このファイル
```

## 開発方針

### ファイル構成
- ゲームは `docs/index.html` をエントリーポイントとして開発します
- コードは適切にファイル分割し、保守性を高めます
  - JavaScript: 機能ごとに別ファイルに分割
  - CSS: スタイルシートを別ファイルで管理
  - アセット: 画像、音声などは適切なディレクトリに配置

### 開発ルール
- **日本語運用**: Pull Request、コミットメッセージ、コメントは日本語で記載
- **ドキュメント更新**: 機能追加時は必ずREADMEも更新
- **コード品質**: クリーンで保守性の高いコードを心がける

## セットアップ

現在、特別なセットアップは不要です。`docs/index.html` をブラウザで開くことでローカルでの動作確認ができます。
