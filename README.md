# GameJam2

社内ゲームジャム向けWeb3ゲーム開発プロジェクト

## 概要

このリポジトリは、社内ゲームジャム向けにWeb3技術を使用したゲームを開発するためのプロジェクトです。GitHub Pagesを使用してゲームを公開します。

現在、ファミコン版ドンキーコングをベースにしたゲームを実装しています。

## 実装ゲーム：ドンキーコング

ファミコン版ドンキーコングを再現したアクションゲームです。

### ゲームの特徴
- **クラシックなプラットフォームアクション**: マリオを操作して、プラットフォームとはしごを使って上を目指します
- **ドンキーコングとの対決**: 画面上部にいるドンキーコングがタルを投げてきます
- **斜めのプラットフォーム**: タルの転がる方向が視覚的にわかりやすい斜めのステージデザイン
- **プリンセスの救出**: 最上階のプリンセスのところまで辿り着くとステージクリア
- **3つのライフ**: タルに当たるか落下するとライフが減ります

### 操作方法
- **方向キー（左右）**: プレイヤーの移動
- **スペースキー**: ジャンプ
- **方向キー（上下）**: はしごの昇り降り

### ゲームシステム
- タルを避けながらプラットフォームを登っていく
- 斜めのプラットフォーム上をタルが転がり、下り坂では加速、上り坂では減速する
- はしごを使って上の階層に移動
- プリンセスに到達するとステージクリア
- スコアシステムとライフシステムを実装

## 技術スタック

- **フロントエンド**: HTML5 Canvas, CSS3, JavaScript (ES6+)
- **Web3**: ブロックチェーン連携機能（今後実装予定）
- **ホスティング**: GitHub Pages

## 開発方針

### ファイル構成
- ゲームは `docs/index.html` をエントリーポイントとして開発
- コードは機能ごとに適切にファイル分割
  - JavaScript: クラスベースの設計で各エンティティを独立したファイルに分割
  - CSS: スタイルシートを別ファイルで管理
  - アセット: 画像、音声などは適切なディレクトリに配置

### コード構造
- **config.js**: ゲーム定数とレベル設計
- **player.js**: プレイヤーキャラクターの動作・物理演算・衝突判定
- **barrel.js**: タルの動作・物理演算・衝突判定
- **donkeykong.js**: ドンキーコングとプリンセスの描画・アニメーション
- **game.js**: ゲームループ、エンティティ管理、ゲーム状態管理
- **main.js**: UI制御、画面遷移、ゲーム全体の管理

### 開発ルール
- **日本語運用**: Pull Request、コミットメッセージ、コメントは日本語で記載
- **ドキュメント更新**: 機能追加時は必ずREADMEも更新
- **コード品質**: クリーンで保守性の高いコードを心がける

## セットアップ

特別なセットアップは不要です。

### ローカルでの動作確認方法

1. **簡易サーバーを起動**:
   ```bash
   cd docs
   python3 -m http.server 8080
   ```

2. **ブラウザでアクセス**:
   `http://localhost:8080/index.html` を開く

または、`docs/index.html` を直接ブラウザで開くこともできます。
