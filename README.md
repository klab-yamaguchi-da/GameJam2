# GameJam2

社内ゲームジャム向けWeb3ゲーム開発プロジェクト

## 概要

このリポジトリは、社内ゲームジャム向けにWeb3技術を使用したゲームを開発するためのプロジェクトです。GitHub Pagesを使用してゲームを公開します。

現在、ファミコン版ドンキーコングをベースにした「運べ！引っ越し荷物」というゲームを実装しています。

## 実装ゲーム：運べ！引っ越し荷物

ファミコン版ドンキーコングを再現したアクションゲームです。

### ストーリー
引っ越しの最後の荷物を４つ運び忘れていた！けど、もう引っ越し先で引っ越し祝いの宴会が始まっている。飲みたくなっちゃうので酒瓶を避けながら荷物運びしよう。

各レベルごとに異なるストーリーと荷物の状態が設定されています：
- **LEVEL1**: 「引っ越しの最後の荷物を４つ運び忘れていた！」
- **LEVEL2**: 「次の荷物は軽いけどゆっくり運ばなきゃ」
- **LEVEL3**: 「次の荷物は重いけど台車がある」
- **LEVEL4**: 「最後の荷物は急がなきゃ」

### ゲームの特徴
- **クラシックなプラットフォームアクション**: 新入社員を操作して、プラットフォームとはしごを使って上を目指します
- **酔っぱらいとの攻防**: 画面上部にいる酔っぱらいが酒瓶を投げてきます
- **光る扉へのゴール**: 最上階の光る扉まで辿り着くとステージクリア
- **複数のレベル**: 
  - **LEVEL1**: 通常の難易度でゲームの基本を習得
  - **LEVEL2**: 移動速度が0.7倍に低下し、ジャンプ力が1.5倍に増加。荷物が軽くなり高く跳べるが、ゆっくり運ぶ必要がある
  - **LEVEL3**: 移動速度は通常だが、ジャンプができない。台車で運ぶため、はしごのみで上階を目指す必要がある
  - **LEVEL4**: 通常の移動速度とジャンプ力だが、20秒のタイムリミット付き。画面左下にカウントダウンタイマーが表示される
- **エンディング**: LEVEL4をクリアすると、赤文字で「ゲームクリア」と表示され、「すべて運びきった。これで気分よく酒が飲めるぞ！」というメッセージが表示されます
- **3つのライフ**: 酒瓶に当たるか落下するとライフが減ります
- **ゴミ箱システム**: 画面右下のゴミ箱に酒瓶が当たると自動的に回収され、スコアが加算されます
- **常時表示の操作方法**: ゲーム画面上部に操作方法が常に表示されるため、初心者でも安心してプレイ可能

### 登場キャラクター
- **プレイヤー**: 水色のスーツを着た新入社員。段ボール箱を運びながら移動します
- **酔っぱらい**: 赤い顔で黄緑の服を着た酔っぱらい。上部から酒瓶を投げてきます
- **酒瓶**: 緑色のガラス瓶で「酒」のラベル付き。避けながら進む必要があります
- **光る扉**: 黄金色に輝くゴール地点。ここまで到達するとステージクリアです
- **ゴミ箱**: 画面右下に設置されたグレーのゴミ箱。酒瓶を回収し、画面に溜まらないようにします

### 操作方法
- **方向キー（左右）**: プレイヤーの移動
- **スペースキー**: ジャンプ
- **方向キー（上下）**: はしごの昇り降り
  - **上キー**: はしごを登る
  - **下キー**: はしごを降りる。プラットフォーム上で下キーを押すと、足元にある梯子を掴んで降りることができます

### ゲームシステム
- 酒瓶を避けながらプラットフォームを登っていく
- はしごを使って上の階層に移動
  - 上のプラットフォームから下キーを押すことで、足元の梯子を掴んで降りられます
- 光る扉に到達するとステージクリア
- 各レベルに異なる難易度設定:
  - **LEVEL1**: 基本的な移動速度とジャンプ力
  - **LEVEL2**: 移動速度が遅くなり（0.7倍）、ジャンプ力が上がる（1.5倍）
  - **LEVEL3**: 通常の移動速度だが、ジャンプ不可。はしごのみで移動
  - **LEVEL4**: 通常の移動速度とジャンプ力だが、20秒のタイムリミット付き
- 画面右下のゴミ箱に落ちた酒瓶が当たると自動的に回収される
- ゴミ箱に酒瓶が当たるとスコアが加算される（100ポイント）
- ステージクリアでボーナススコア（1000ポイント）
- スコアシステムとライフシステムを実装

### サウンドシステム
- **8ビット風のレトロなサウンド**: Web Audio APIを使用して、すべての音をプログラムで生成
- **レベルBGM**: 各ステージで流れる8秒ループのチップチューン風メロディ
- **歩行SE**: プレイヤーが地面を歩くときの短いピッピッという音
- **ジャンプSE**: ジャンプ時に鳴る周波数が上昇する音
- **死亡SE**: プレイヤーが酒瓶に当たったり落下したりしたときの下降音
- **ステージクリアSE**: ステージクリア時のファンファーレ風の音
- **ゲームクリア音楽**: 全ステージクリア時に流れる20秒の勝利の音楽

## 開発方針

### ファイル構成
- ゲームは `docs/index.html` をエントリーポイントとして開発
- コードは機能ごとに適切にファイル分割
  - JavaScript: クラスベースの設計で各エンティティを独立したファイルに分割
  - CSS: スタイルシートを別ファイルで管理
  - アセット: 画像、音声などは適切なディレクトリに配置

### コード構造
- **config.js**: ゲーム定数とレベル設計（LEVEL1〜4のマップ・難易度設定、タイムリミット設定）
- **audio.js**: 音響システム（Web Audio APIを使用した8ビット風サウンド生成・管理）
- **player.js**: プレイヤーキャラクター（新入社員）の動作・物理演算・衝突判定。レベル固有の速度・ジャンプ力倍率に対応。歩行・ジャンプ音の再生
- **barrel.js**: 酒瓶の動作・物理演算・衝突判定
- **trashbin.js**: ゴミ箱の描画・ボトルとの衝突判定
- **donkeykong.js**: 酔っぱらいと光る扉の描画・アニメーション
- **game.js**: ゲームループ、エンティティ管理、ゲーム状態管理、レベルロード処理、タイムリミット機能、死亡音の再生
- **main.js**: UI制御、画面遷移、ゲーム全体の管理（タイトル→ストーリー→ゲーム→ステージクリア→次レベル）、BGM・効果音の管理

### 開発ルール
- **日本語運用**: Pull Request、コミットメッセージ、コメントは日本語で記載
- **ドキュメント更新**: 機能追加時は必ずREADMEも更新
- **コード品質**: クリーンで保守性の高いコードを心がける

## セットアップ

特別なセットアップは不要です。

### ローカルでの動作確認方法

1. **簡易サーバーを起動**:
   ```bash
   cd docs
   python3 -m http.server 8080
   ```

2. **ブラウザでアクセス**:
   `http://localhost:8080/index.html` を開く

または、`docs/index.html` を直接ブラウザで開くこともできます。
